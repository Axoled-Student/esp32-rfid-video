# 影片放這個資料夾

把 8 部影片改名成這樣丟進來：

```
1.mp4
2.mp4
3.mp4
4.mp4
5.mp4
6.mp4
7.mp4
8.mp4
```

## 規則

- **檔名必須正好是 `1.mp4` ~ `8.mp4`** —— 大小寫、副檔名都要一樣，程式是照這個去抓的
- **每個檔案不能超過 100MB** —— GitHub 的硬性限制，超過會推不上去
- 格式建議用 **MP4 (H.264)**，瀏覽器相容性最好

## 檔案太大怎麼辦

用線上工具壓縮，或是裝 ffmpeg 跑這行：

```
ffmpeg -i 原始檔.mp4 -vcodec libx264 -crf 28 1.mp4
```

`-crf` 數字越大檔案越小、畫質越差，28 左右通常剛好。
