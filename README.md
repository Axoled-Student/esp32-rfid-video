# ESP32 刷卡播放影片

刷 RFID 卡片 → 网页自动播放对应的第 1~8 部影片。

## 运作方式

```
        刷卡
         ↓
  ESP32 + RC522  ← 在你家局域网，同时兼任小网站
         ↓ 提供网页
  浏览器 http://192.168.x.x
         ↓ 影片从这里拉
  GitHub Pages 上的 8 部 mp4  ← 公网
```

**为什么这样拆？** ESP32 只有 4MB 空间，塞不下影片；而 GitHub Pages 在公网上、碰不到你家局域网里的 ESP32。所以让 ESP32 负责「侦测刷卡 + 提供网页」，影片放 GitHub。

## 档案说明

| 路径 | 用途 |
|---|---|
| `esp32_rfid_video/esp32_rfid_video.ino` | 烧进 ESP32 的程序 |
| `videos/1.mp4` ~ `videos/8.mp4` | 8 部影片（**档名必须正好这样**） |
| `index.html` | 测试页，用来确认影片有没有传对 |

## 使用步骤

### 1. 放影片

把 8 部影片改名成 `1.mp4` ~ `8.mp4`，丢进 `videos/` 资料夹。

> ⚠️ **每个档案不能超过 100MB**（GitHub 的硬性限制）。太大的话先压缩。

### 2. 测试影片

开 https://vin836.github.io/esp32-rfid-video/
点按钮能播出来，就代表影片没问题。

### 3. 装 Arduino 环境

- Arduino IDE → 工具 → 管理库 → 搜 `MFRC522` → 装 **miguelbalboa** 那个
- 工具 → 开发板 → `ESP32 Dev Module`
- 工具 → 端口 → 插上板子后出现的 COM 口

### 4. 接线（RC522 → ESP32）

| RC522 | ESP32 |
|---|---|
| SDA (SS) | GPIO 5 |
| SCK | GPIO 18 |
| MOSI | GPIO 23 |
| MISO | GPIO 19 |
| RST | GPIO 27 |
| **3.3V** | **3.3V** ⚠️ 接 5V 会烧掉模块 |
| GND | GND |

IRQ 脚不用接。

### 5. 改程序里的设定

打开 `.ino`，只有最上面框起来那一区要改：

- `WIFI_SSID` / `WIFI_PASS` —— 你家 Wi-Fi（**必须是 2.4G，ESP32 不支持 5G**）
- `CARD_UID[8]` —— 8 张卡的 UID
- `VIDEO_NAME[8]` —— 影片标题（随意改）

### 6. 抄卡片 UID

先随便烧进去，打开串口监视器（右上角放大镜，波特率选 **115200**），刷一张卡，会看到：

```
---------------------------------------
未登记的卡，UID 是：  A3 5F 21 9C
请复制这串，贴到程序上方 CARD_UID 里
---------------------------------------
```

把 8 张卡都刷一遍，抄下 8 串 UID 贴进 `CARD_UID`，重新烧录即可。

### 7. 开始用

串口会印出网址：

```
========================================
  网页地址：http://192.168.1.87
  用手机或电脑浏览器打开上面这行
========================================
```

浏览器打开 → 点一下画面（浏览器规定要先互动才准自动播放）→ 刷卡就会播了。

## 常见问题

**上传时卡在 `Connecting......`**
按住板子上的 **BOOT** 按钮几秒再放开。ESP32 常见小脾气，不是坏了。

**刷卡没反应**
检查 RC522 电源是不是接在 3.3V，还有 UID 有没有贴对（大小写、空格都要一样）。

**网页打得开但影片不播**
先开测试页（步骤 2）确认影片本身没问题，再看 `.ino` 里的 `VIDEO_BASE` 网址结尾有没有斜线 `/`。

**手机连不上 ESP32 的网页**
手机要跟 ESP32 连同一个 Wi-Fi。
