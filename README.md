# ESP32 刷卡播放影片 🎬

刷 RFID 卡片 → 網頁自動播放對應的第 1~8 部影片。

## 網址

| 頁面 | 網址 | 用途 |
|---|---|---|
| 測試頁 | https://vin836.github.io/esp32-rfid-video/ | 確認 8 部影片能不能播 |
| 上傳面板 | https://vin836.github.io/esp32-rfid-video/upload.html | 換影片用，瀏覽器直接上傳 |

## 運作方式

```
        刷卡
         ↓
  ESP32 + RC522  ← 在你家區網，同時兼任小網站
         ↓ 提供網頁
  瀏覽器 http://192.168.x.x
         ↓ 影片從這裡拉
  GitHub Pages 上的 8 部 mp4  ← 公網
```

**為什麼這樣拆？** ESP32 只有 4MB 空間，塞不下影片；而 GitHub Pages 在公網上、碰不到你家區網裡的 ESP32。所以讓 ESP32 負責「偵測刷卡 + 提供網頁」，影片放 GitHub。

## 換影片怎麼做

1. 開 https://vin836.github.io/esp32-rfid-video/upload.html
2. 貼上金鑰（第一次要弄，之後瀏覽器會記住）
3. 點方格選影片
4. 按「開始上傳」

上傳完雲端會自動轉檔，約 3~5 分鐘，然後就上線了。

**什麼格式都可以** —— mov / avi / mkv / mp4 都吃，雲端會自動轉成網頁能播的格式，還會自動壓小。

> 單檔請低於 100MB（GitHub 規定）。

### 金鑰怎麼拿

上傳面板裡有連結，或直接開 https://github.com/settings/tokens/new?scopes=repo,workflow

權限勾 `repo` 和 `workflow`，按最下面的綠色按鈕，複製那串 `ghp_` 開頭的字。

> 金鑰只存在你自己的瀏覽器裡，不會傳給別人。

## ESP32 設定

### 1. 裝環境

- Arduino IDE → 工具 → 管理程式庫 → 搜 `MFRC522` → 裝 **miguelbalboa** 那個
- 工具 → 開發板 → `ESP32 Dev Module`
- 工具 → 序列埠 → 插上板子後出現的 COM 埠

### 2. 接線（RC522 → ESP32）

| RC522 | ESP32 |
|---|---|
| SDA (SS) | GPIO 5 |
| SCK | GPIO 18 |
| MOSI | GPIO 23 |
| MISO | GPIO 19 |
| RST | GPIO 27 |
| **3.3V** | **3.3V** ⚠️ 接 5V 會燒掉模組 |
| GND | GND |

IRQ 腳不用接。

### 3. 改程式

打開 `.ino`，只有最上面框起來那一區要改：

- `WIFI_SSID` / `WIFI_PASS` —— 你家 Wi-Fi（**必須是 2.4G，ESP32 不支援 5G**）
- `CARD_UID[8]` —— 8 張卡的 UID
- `VIDEO_NAME[8]` —— 影片標題（隨意改）

影片網址已經幫你填好了，不用動。

### 4. 抄卡片 UID

先隨便燒進去，打開序列埠監控視窗（右上角放大鏡，鮑率選 **115200**），刷一張卡會看到：

```
---------------------------------------
未登記的卡，UID 是：  A3 5F 21 9C
請複製這串，貼到程式上方 CARD_UID 裡
---------------------------------------
```

8 張卡都刷一遍，抄下 UID 貼進 `CARD_UID`，重新燒錄即可。

### 5. 開始用

序列埠會印出網址：

```
========================================
  網頁地址：http://192.168.1.87
  用手機或電腦瀏覽器打開上面這行
========================================
```

瀏覽器打開 → 點一下畫面（瀏覽器規定要先互動才准自動播放）→ 刷卡就會播了。

## 常見問題

**上傳程式時卡在 `Connecting......`**
按住板子上的 **BOOT** 按鈕幾秒再放開。ESP32 常見小脾氣，不是壞了。

**刷卡沒反應**
檢查 RC522 電源是不是接在 3.3V，還有 UID 有沒有貼對（大小寫、空格都要一樣）。

**網頁打得開但影片不播**
先開測試頁確認影片本身沒問題。

**手機連不上 ESP32 的網頁**
手機要跟 ESP32 連同一個 Wi-Fi。

**上傳面板說金鑰無效**
金鑰有期限，過期要重拿一組。權限記得勾 `repo` 和 `workflow`。
