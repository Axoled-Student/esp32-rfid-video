# ESP32 刷卡展示系統 🎬

刷 RFID 卡片 → 平板自動打開對應的網站或影片。

## 網址

| 頁面 | 網址 | 用途 |
|---|---|---|
| **展示頁** | https://vin836.github.io/esp32-rfid-video/play.html | 展示用，平板開這個 |
| 測試頁 | https://vin836.github.io/esp32-rfid-video/ | 確認 8 張卡的內容都正常 |
| 上傳面板 | https://vin836.github.io/esp32-rfid-video/upload.html | 換影片 |
| 模擬刷卡 | https://vin836.github.io/esp32-rfid-video/模擬刷卡.html | 板子還沒接好時測試用 |

### 怎麼換網址

開 `assets/config.js`，找到 `CONFIG.CARDS`，把對應那張的 `url` 換掉就好：

```js
{
  type:  'site',                       // 'site' 開網站，'video' 播影片
  title: 'CHAPTER 01 · 布農族',        // 刷卡時顯示的標題
  url:   'https://你的網址',
},
```

改完推上 GitHub，1~2 分鐘後生效。

> **⚠ 有些網站不准被嵌入**，畫面會一片空白。
> 維基百科要用手機版 `zh.m.wikipedia.org`（電腦版會被擋）。
> YouTube、Google 也不能直接嵌。不確定的話先在展示頁刷刷看，
> 開不起來會跳出提示，可以按按鈕用新分頁開。

## 運作方式

```
      刷卡
       ↓
  ESP32 + RC522
       ↓ 發訊息
  MQTT 中繼站（公網）
       ↓ 收訊息
  平板的展示頁 → 開對應的網站（或播影片）
```

ESP32 只有 4MB 空間塞不下影片，所以影片放 GitHub、ESP32 只負責偵測刷卡。
中間用 MQTT 傳訊息，**平板跟 ESP32 不用連同一個 Wi-Fi**，平板用行動網路也可以。

# 一、換影片

1. 開 https://vin836.github.io/esp32-rfid-video/upload.html
2. 貼上金鑰（第一次要弄，之後瀏覽器會記住）
3. 點格子選影片，或直接把檔案拖進去
4. 按「開始上傳」

上傳完雲端會自動轉檔，約 3~5 分鐘，面板上會即時顯示進度。

**什麼格式都可以** —— mov / avi / mkv / mp4 都吃，雲端會自動轉成網頁能播的格式，
太大的還會自動壓小。單檔請低於 100MB（GitHub 規定）。

### 金鑰怎麼拿

上傳面板裡有連結，或直接開
https://github.com/settings/tokens/new?scopes=repo,workflow

權限勾 `repo`，按最下面的綠色按鈕，複製那串 `ghp_` 開頭的字。

> 金鑰只存在你自己的瀏覽器裡，不會傳給別人。

# 二、ESP32 設定

## 1. 裝環境

- Arduino IDE → 工具 → 管理程式庫，搜尋並安裝這兩個：
  - **MFRC522** by miguelbalboa
  - **PubSubClient** by Nick O'Leary
- 工具 → 開發板 → `ESP32 Dev Module`
- 工具 → 序列埠 → 插上板子後出現的 COM 埠

## 2. 接線（RC522 → ESP32）

| RC522 | ESP32 |
|---|---|
| SDA (SS) | GPIO 5 |
| SCK | GPIO 18 |
| MOSI | GPIO 23 |
| MISO | GPIO 19 |
| RST | GPIO 27 |
| **3.3V** | **3.3V** ⚠️ 接 5V 會燒掉模組 |
| GND | GND |

IRQ 腳不用接。

## 3. 燒錄

打開 `esp32_rfid_video/esp32_rfid_video.ino`，直接燒進去就好。

**Wi-Fi 不用寫在程式裡** —— 燒完之後用手機設定（見下一步）。

## 4. 設定 Wi-Fi（用手機，不用改程式）

第一次開機，板子會自己開一個 Wi-Fi 熱點：

1. 手機的 Wi-Fi 清單找 **「刷卡機-設定」**
2. 密碼輸入 `12345678`
3. 連上後手機會自動跳出設定畫面
   （沒跳的話，瀏覽器打 `http://192.168.4.1`）
4. 選你家的 Wi-Fi、填密碼、按「儲存並連線」

設定會記在板子裡，之後開機自動連，不用再設一次。

> **熱點會開 10 分鐘**，逾時會自動重開再開一次，不用擔心錯過。
>
> ⚠️ 只能連 **2.4GHz** 的 Wi-Fi。如果路由器兩個頻段同名，可能要先分開命名。

### 板子的燈在說什麼

| 燈號 | 意思 |
|---|---|
| 慢慢閃（1 秒 1 下） | 設定模式，等你用手機來設定 |
| 不亮 | 正常運作中，等你刷卡 |
| 閃 1 下 | 刷卡成功，訊息送出去了 |
| 快閃 3 下 | 訊息沒送出去，稍後會自動重連 |
| 快閃 8 下 | 網路設定已清除，準備重開 |

## 5. 重新設定 Wi-Fi

換地方展示、或 Wi-Fi 改密碼了：

**按住板子上的 BOOT 鍵 3 秒** → 燈快閃 8 下 = 清除完成，
板子會自己重開並再開一次設定熱點。

> 按的時候燈會越閃越快，放太早會取消，要按滿 3 秒。
>
> 如果 Wi-Fi 連續 3 次連不上，板子也會自動開設定熱點。

## 6. 抄卡片 UID

燒完打開序列埠監控視窗（右上角放大鏡，鮑率選 **115200**），刷一張卡會看到：

```
─────────────────────────────────────
未登記的卡，UID 是：  A3 5F 21 9C
請複製這串，貼到程式上方 CARD_UID 裡
─────────────────────────────────────
```

8 張卡都刷一遍，抄下 UID 貼進程式最上面的 `CARD_UID`，重新燒錄即可。

## 7. 開始展示

1. 平板開 https://vin836.github.io/esp32-rfid-video/play.html
2. **點一下畫面**（iPad Safari 規定要先碰一下，影片才能出聲音）
3. 刷卡就會開了

展示頁的貼心設計：
- 自動防止平板睡著
- 網站滿版顯示，iPad 直的橫的都會自己調整
- 閒置 3 秒後角落的按鈕會淡掉，畫面留給內容
- **要叫回按鈕就把手指移到畫面最上緣**（網站蓋住畫面時的出路）
- 左上角有全螢幕鈕、「回待機」鈕

| 路徑 | 用途 |
|---|---|
| `play.html` | 播放頁（展示用） |
| `index.html` | 測試頁 |
| `upload.html` | 上傳面板 |
| `模擬刷卡.html` | 模擬刷卡（測試用） |
| `assets/config.js` | **全站設定**，要改東西改這裡 |

| `esp32_rfid_video/esp32_rfid_video.ino` | 燒進 ESP32 的程式 |

| `raw/` | 原始影片（上傳面板會自動放這裡） |
| `videos/` | 轉好的影片（自動產生，不用自己動） |
| `tests/` | Playwright 測試腳本 |

## 想改東西

**每張卡開什麼** —— 改 `assets/config.js` 的 `CONFIG.CARDS`（詳見最上面的說明）。

**卡片數量** —— 改 `assets/config.js` 的 `COUNT`，
以及 `.ino` 裡的 `CARD_UID` 和 `convert.yml` 裡的 `for n in 1 2 3...`。

**畫質** —— 改 `convert.yml` 最上面的 `CRF`，數字越大檔案越小也越糊。

**要不要保留原始影片** —— 改 `convert.yml` 的 `DELETE_RAW`。
預設 `true`（轉完就刪，省空間）。

# 四、常見問題

**燒錄時卡在 `Connecting......`**
按住板子上的 **BOOT** 鍵幾秒再放開。ESP32 常見小脾氣，不是壞了。

**手機找不到「刷卡機-設定」熱點**
熱點只開 10 分鐘。按一下板子的 EN 鍵重開，或按住 BOOT 鍵 3 秒。

**設定畫面填了 Wi-Fi 但連不上**
確認是 **2.4GHz** 的，ESP32 連不到 5GHz。密碼也要再確認一次。

**刷卡沒反應**
先看序列埠有沒有印東西。
- 完全沒反應 → 檢查 RC522 電源是不是 3.3V、接線對不對
- 印出「未登記的卡」→ UID 沒貼對，照著印出來的複製
- 印出「送出失敗」→ 網路問題，等它自動重連

**播放頁一直顯示「連線中」**
平板需要能上網。確認 Wi-Fi 或行動網路正常。

**播放頁點了畫面但刷卡沒播**
確認播放頁右上角是綠燈「已連線」。板子那邊刷卡時序列埠要印出「播放第 N 部」。

**刷卡後畫面一片空白**
那個網站不准被嵌入。等 12 秒會跳出提示，可以按按鈕用新分頁開。
維基百科記得用手機版 `zh.m.wikipedia.org`。

**網站開了，但角落按鈕不見了叫不回來**
把手指移到畫面**最上緣**（或滑鼠移過去），按鈕就會回來。
網站是嵌在畫面裡的，碰它我們收不到訊號，所以在最上面留了一條感應區。

**影片播不出來**
先開測試頁，它會自動檢查每張卡的內容在不在。

**上傳面板說金鑰無效**
金鑰有期限，過期要重拿一組。權限記得勾 `repo`。

# 五、開發者

跑測試（需要先開本地伺服器）：

```bash
npx http-server -p 8899 -c-1     # 另開一個終端機

node tests/sites.mjs              # 測 8 張卡的網站節點（iPad 尺寸）
node tests/smoke.mjs              # 測四個網頁的基本功能
node tests/setup-page.mjs         # 測 ESP32 設定畫面
```

編譯韌體（不用開 Arduino IDE）：

```bash
arduino-cli compile --fqbn esp32:esp32:esp32 esp32_rfid_video
```
